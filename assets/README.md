# Portfolio Asset Plan

本目录只接收脱敏、已授权、适合公开求职展示的素材。

## Recommended files

| 文件 | 内容 | 建议规格 |
|---|---|---|
| `hero.webp` | 15 秒主流程 | 960px 宽，循环，建议小于 10MB |
| `core-loop.png` | 五步游戏化闭环 | 1600 × 900，静态 |
| `press-states.png` | 0% / 中段 / 满格三联图 | 1600 × 900，静态 |
| `feedback-timeline.png` | 视觉、声音、振动、文案时间线 | 1600 × 900，静态 |
| `three-track.webp` | 同动作三轨对比 | 1440px 宽，短循环 |
| `decision-c.png` | C 轨决策卡 | 1600 × 900，静态 |
| `fallback.webp` | 失败解释与降级 | 960px 宽，短循环 |
| `seal-record.png` | 封印与 Home 记录 | 1600 × 900，静态 |

## Capture rules

- 使用专门准备的演示环境或经过许可的模拟目标；
- 裁掉人脸、纹身、家庭环境、通知栏、定位和设备标识；
- 不录入真实 AppID、调试日志、阈值、坐标或内部开关；
- 视频关闭麦克风，后期另配已授权声音；
- 素材元数据在发布前清理；
- 用户原话不得直接截图，改为匿名汇总或取得书面许可；
- 每个第三方资产记录来源、授权范围和是否允许公开展示。

## Publishing rule

任何素材只有在“隐私、版权、商业保密”三项均通过后才加入 Git。
