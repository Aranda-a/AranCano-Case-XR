## 待补

| 文件 | 内容 | 建议规格 |
|------|------|----------|
| `hero.webp` 或外链 | 约 15 秒主流程 Hero | 960 像素宽，循环，建议小于 10MB |
| 完整走查 | 约 45–60 秒 | GitHub Release 或外链，勿塞大 MP4 进主仓 |
| `three-track` | B/C 同镜对比 | 短循环 |
| 满格塌陷帧 | 按压高潮瞬间 | 静图或短片 |
| 失败降级真机 | 进入失败 → 改走轻量平面 | 短循环 |

## 拍摄与脱敏

- 使用专门准备的演示环境或经过许可的局部皮肤目标
- 裁掉人脸、纹身、家庭环境、通知栏、定位和设备标识
- 开发者工具鼠标指针尽量裁掉后再发下一版
- 视频关闭麦克风，后期另配已授权声音
- 素材元数据在发布前清理
- 用户原话不得直接截图，改为匿名汇总或取得书面许可

## 发布

任何素材只有在隐私、版权、商业保密三项均通过后才加入版本库。
