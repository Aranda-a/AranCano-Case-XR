# AranCano

身体会突然要你做一下。我们让这一下有对象、有进度、有结束。

对准蚊子包，按住，把它按平，盖个章。抓挠往往只有一下，却没有句号。AranCano 不把这股劲拉成一局游戏，而是收成一次能做完、也能停的动作。

微信小程序交互原型，真机还在打磨。不是看病，也不保证消肿。

**怎样算做成了**

- 屏幕上那一团，像贴在你的包上，不是漂在旁边的贴纸
- 你按的时候，它瘪、它响、它震，是同一件事
- 按满了会塌、会盖章，你会想松手，而不是再找下一关

```
对准真包 → 可按的替身 → 按住才走 → 满了就塌 → 盖章进记录
```

**手会雇谁**

被咬那一下，手通常先抓、拍、抹、忍，或去刷手机。我们抢的是这只手，不是再做一款相机滤镜。把痒变成能按的一颗，按完有句号。

**游戏化，围着「做完」**

1. **先有能按的东西。** 软一点是火山包子，Q 一点是火山果冻。那是它长什么样，不是再选一套皮肤。
2. **得你亲手按。** 进度条不自己爬。按住才涨，一松就停。
3. **眼睛、耳朵、手听同一句话。** 瘪、声、振、那行小字，一起走，满了一起收。
4. **结束本身就是功能。** 塌和章是句号。记录给人回头翻，不是催打卡。

Annno 在旁边晃两下，像同伴，不当第二局。

**这一刀**

三条路做同一件事：主路径 **贴住**（转一转还有点远近）；跟手留下来对比；进不去就走 **轻量**，闭环不变，照样能按完。

漂比进门失败更出戏。进不去可以再试、可以换轻的；一直飘，人会一直觉得在玩滤镜。
