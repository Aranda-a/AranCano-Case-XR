# Validation Plan

## Purpose

验证空间贴附、按压反馈和结束感是否成立，并为三轨角色提供证据。

本计划属于配对可用性测试，不是随机分流 A/B 实验。

## Method

- 同一参与者体验需要比较的方案；
- 交替安排体验顺序，减少先后顺序影响；
- 使用相同环境、目标和基础任务；
- 不在体验前解释技术路线；
- 先记录行为，再询问原因。

## Task

参与者完成一次对准、按压、满格和封印流程，并在提示下轻微移动镜头观察空间关系。

## Evidence

### Behavioral

- 是否独立完成；
- 首次对准与整体完成耗时；
- 重试、误触和降级次数；
- 是否在满格前意外松手；
- 是否主动再次操作。

### Perceptual

- 模型是否像贴在目标上；
- 镜头移动时是否明显漂移；
- 按压力度是否连续可感；
- 满格反馈是否足够突出；
- 完成后是否形成结束感。

### Preference

- 更偏好哪一种体验；
- 偏好的具体原因；
- 最破坏真实感的瞬间；
- 最有释放感的瞬间。

## Decision Discipline

- 测试前写明本轮要判断的问题；
- 不用单一满意度替代行为证据；
- 不把少量质性反馈包装成统计结论；
- 发现失败时先判断属于空间、反馈还是理解问题；
- 结论必须同时记录限制与回退条件。

## Privacy

- 参与者明确知情并同意记录；
- 默认不录人脸、环境身份信息和系统通知；
- 公开材料只使用匿名汇总或获许可改写；
- 原始视频、照片和访谈不进入公开仓；
- 研究材料设置保存期限并限制访问。

## Public Output

公开作品集中只呈现：

- 脱敏后的任务说明；
- 汇总行为现象；
- 不可识别的代表性观察；
- 方案取舍及其限制；
- 不包含内部参数的对比演示。
