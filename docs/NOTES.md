# 拍摄与验证

正文里的结论在 [这一版怎么做的](PRODUCT.md) 第 7 节。这里只记怎么拍、这一轮怎么看。

## 演示怎么拍

- 专门布置的环境；画面以手、包、替身为主。
- 全流程一条：对准 → 出现 → 按瘪 → 塌 → 章。建议 12～15 秒，做成 `assets/hero.webp` 或 `hero.gif`。
- 五帧顺序图：框住、按住、按满、盖章、记录。
- 按的三态：还没按、一半、满格。
- 需要对比时，同一只包、同一段转镜头，看贴住和跟随差在手感，不看参数。
- 声音后期配；屏幕上的字只留用户看得到的。

## 这一轮怎么看

同一位参与者、同一台设备、相近光线、同一颗包，先后走要比较的两条路。一半人先走贴住，一半人先走对照，减轻「谁先谁后」的影响。每一次都走完整闭环。先看人怎么做，再问为什么。

主要问：哪一次更像按在真实的包上。也看：按着像不像那么回事、能不能按满盖章、做完还想不想抓。

人少时只写看见的模式和失败卡在哪。不把少量观察说成大盘实验。

记录用匿名编号：设备大概档位、谁先谁后、两路是否做完、卡在哪、一句改写过的原话。画面默认不收入脸和能认出地方的背景。
