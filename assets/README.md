# 演示素材

把已经裁好、可以公开看的文件放在这一层。封面会引用 `hero.webp` 或 `hero.gif`。

| 文件 | 放什么 |
|------|--------|
| `hero.webp` / `hero.gif` | 一次按完的短循环 |
| `overview.png` | 气质总览（多画面合一张也可以） |
| `loop-5.png` | 五帧顺序：框住 → 按住 → 按满 → 盖章 → 记录 |
| `press-3.png` | 还没按 / 一半 / 满格 |
| `timeline.png` | 视、声、振、字同一条线 |
| `attach-vs-follow.webp` | 同一段转镜头，两种空间手感 |
| `fallback.webp` | 进不去时仍能按完 |
| `seal-record.png` | 章，和记下的那一笔 |

拍摄时以手、包、替身为准。第三方字体、声音、模型，确认可以公开展示再用。
