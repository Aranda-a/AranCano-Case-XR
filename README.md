# AranCano · 游戏化蚊子包交互（XR 主路径）

**角色标签：** 产品原型 · 交互设计 · XR 空间交互 · 陪伴型 IP（Annno）

**我的角色：** 独立完成的 0–1 原型。问题定义、主路径交互、多通道反馈、真机验证与埋点口径由作者负责；开发与文档使用 AI 辅助提速。本页展示产品决策与验证结果，不含核心实现。

> 转移注意力：把皮肤发痒引起的持续抓挠冲动，变成一次可按压的游戏化摄像头交互。

AranCano 是微信小程序交互原型。用户对准真实蚊子包后，屏幕生成可按压的视觉替身；长按驱动形变、声音与振动，最终以塌陷和封印收束。

产品定位是**行为替代**：在「手已经想动」的那几秒，提供一个对准 → 按住 → 按满 → 做完的屏幕动作。它处理抓挠冲动，不替代药物，也不承诺止痒。完整说明见 [产品说明](docs/CASE-STUDY.md)。

> 本仓为产品案例展示：无源码与算法参数，无原始访谈与可识别身份材料。故事板中的局部皮肤来自作者本人或已获书面许可的演示。

## 2. 要解决什么

**在痒和烦躁同时存在时，给人一个不加重抓挠循环的、好玩且能结束的出口。**

### 常见问题

「涂药或忍一下就好，为什么还要开小程序？」

药品解决的是不适本身；AranCano 解决的是冲动窗口里的手部动作。痒出现后，人常会抓、划或刷手机分心。产品把「手要动一下」做成对准 → 按住 → 按满 → 收束。抓挠可能短暂压住痒感，也可能损伤皮肤、加重循环（[研究](https://www.nature.com/articles/nn.2292) · [综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC6502296/)），因此「别抓」很难只靠意志——这是行为替代的理由，不是疗效声明。

当场能否走完，看本页数据卡；下次痒时是否主动打开，与完成率分开，用日记法验证，见 [验证计划](docs/VALIDATION.md)。

### 入口步骤更多，如何设计

对准与长按比直接抓多几步。产品把它们设计成替代动作的一部分：默认只走一条主路，失败再进退路，避免在冲动时做版本选择。

| 摩擦点 | 设计 | 如何验证 |
|--------|------|----------|
| 比抓挠慢 | 微信直达；默认 C，失败走 A | 数据卡看完成率 |
| 需要对准 | 对准即把手从皮肤移开的第一步 | 引导说明出模与真包的关系 |
| 下次是否打开 | 封印、月历、批语留下完成记忆，不用排行榜或连续登录 | 机制已落地；打开意愿另按日记法观察 |

<details>
<summary><strong>与常见选择对照</strong></summary>

| 选择 | 为何会选 | 优势 | 局限 |
|------|----------|------|------|
| 抓、掐、搓 | 本能、即时 | 最快 | 可能伤皮肤、易循环 |
| 花露水、药膏等 | 处理生理不适 | 熟悉 | 起效因产品而异；涂完手仍可能想动 |
| 热敷、止痒器具等 | 用其他刺激盖过痒 | 触感明确 | 需额外携带 |
| AranCano | 给手一个可完成的屏幕动作 | 微信内可用；形变 + 声 + 振；单主路 + 退路 | 步骤多于直接抓；打开意愿与当场完成率分开验证 |

</details>

## 3. 为何默认 C、保留 A

| 轨道 | 优先保证 | 主要代价 | 角色 |
|------|----------|----------|------|
| **A 轻量平面** | 能打开、能按完 | 更偏贴片感 | 兼容退路 |
| **B 跟手立体** | 跟随红斑 | 易与背景分离、漂移 | 对照，不进默认入口 |
| **C 立体跟包** | 钉在空间中，转手机有视差 | 进场依赖平面识别，设备有差异 | **默认主路径** |

跟手更紧，不等于观感更真。B 一旦迟滞，模型容易和实景脱节。C 把风险集中在进场：可能失败一次，但失败可解释、可重试，并可退到 A。

真机反馈里，有人觉得 C「更像贴在包上」，也有人感知到进场等待——这与「默认 C、失败退 A」一致。更多说明见 [产品说明](docs/CASE-STUDY.md)。

锁定后分两种情况：

1. **手机在动、包基本不动** → 用世界锚稳住模型  
2. **包换了位置** → 用户点「微调贴位」再锁；失败则保持原位  

### 试用反馈如何影响设计（已脱敏）

- 「冒出个能点的东西，不知道和我的包有什么关系。」→ 引导需说明出模与真包的对应；对准是替代动作的第一步。  
- 「放大方向别扭，俯视时更明显。」→ 操作方向需贴合持机姿势。  
- 「只有包在动，和背景割裂。」→ 跟手路径易分家；**因此 B 不进默认入口**，默认走 C、B 仅作对照。  


定量结果见下方数据卡。空间能力不足时走 A；离开页面停止相机与异步任务；图像默认本地处理。

## 4. 轻量数据卡

流程：埋点 → 体验版上报 → 按预定口径入选 → 汇总三指标。

| 指标 | 数值 | 口径 |
|------|------|------|
| 完成率 | 100% | **入选：** 有本局小结的体验版会话；**计完：** 按满并封印；**n=15** |
| 想挠分数前后变化 | ↓45.9 分 | **入选：** 前后探针均认真拖过、未跳过（与完成率分套）；正数表示平均下降；**n=8** |
| 退到轻量 A | 0 次 | 与完成率同一批入选会话；**n=15** |

指标含义：

- **完成率** → 主路径是否能走完（有小结即入选；探针未齐仍计入本项）  
- **想挠变化** → 当场冲动的代理观察（非疗效；未齐探针不入选本项）  
- **退到 A** → 退路是否被触发  

汇总方法见 [METRICS.md](docs/METRICS.md)。

## 5. 游戏化与三通道反馈

| 目标 | 做法 |
|------|------|
| 有对象 | 蚊子包变为可按的火山包子 / 火山果冻；Annno 陪伴，不抢主角 |
| 有进度 | 形变、声音、振动随按压力度变化；松手回弹 |
| 有终点 | 塌陷 + 封印表示做完；月历可回看，不用积分留人 |

封印是完成凭证。长按同时走视觉、听觉、触觉三条线；界面文案只说明当前状态。节奏为：按上 → 蓄力 → 按满收束，进度跟随手指。

下次是否打开与当场完成率分开验证，见 [验证计划](docs/VALIDATION.md)。
